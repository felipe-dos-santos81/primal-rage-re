# Closing every existing gap — Master Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close, or re-scope with raw evidence, every gap the port carries today: unported portable functions, `TODO(verify)` doubts, unported `game_frame` mode cases, and prose "named gaps" — moving no enforced oracle claim.

**Architecture:** Ledger-first. Task 1 turns the four gap sources into one authoritative, address-keyed ledger measured against the current tree (the numbers in this plan are a snapshot and go stale). Tasks 2–6 each close one gap class as a sequence of *cycles*; every cycle is derivation record → per-function port → mutation-proven test → `make verify`, exactly as the earlier `gapNN-*` branches did. Task 7 reconciles docs and the README percentage. This is a master plan: a cycle whose closure is large (>= ~4 KB or >= ~20 new functions) gets its own dated plan and derivation record **before** porting, per the size gate.

**Tech Stack:** C over flat `mem[]` (SDL3 port), CMake, the `CHECK`/`CHECK_EQ_INT` suite, Ghidra MCP (project `rage`, `/PRAGE.EXE`), DOSBox-X for live RAM, Python 3 (`tools/port_progress.py`).

**Spec:** None separate — the scope was fixed by the user ("fix all existing gaps", "everything, in phases") and the contract is `AGENTS.md`, `port/PORTING.md`, `port/RE_GUIDE.md`, `port/spec/game_flow.md`. Prior art for one cycle's shape: `docs/superpowers/plans/2026-09-22-fidelity-gaps.md`.

## Global Constraints

- **No enforced oracle claim moves.** Gate is `make verify` exit 0 with `PR_ORACLE_REQUIRED=1`. Record the pre-change values of every oracle line in Task 1 and compare after each cycle. If a correct fix moves one: **halt**, report old value, new value and the raw evidence; update the claim in the same commit only if justified. Raise the demo-fight / attract2 ratchet N only when it *improves*.
- **Never ship a fitted constant.** Every value comes from raw bytes or a capture, with the address. A value that cannot be pinned is a **named gap with its evidence**, not a plausible number.
- **On any plan-vs-raw conflict the raw wins** — record correction and address in the derivation record and report.
- **Address model:** Ghidra address == linear address; data global `DAT_0008xxxx` = `DS_000xxxx`. Use Ghidra (fixups applied) for data addresses, never raw-file disassembly. Never write `mem[0xA0000]`; composite into `mem + DSD(DS_000E87A4)` and present through `gfx_present()`.
- **One C function per original function**, header `/* 0xADDR — record §N */`. Deviations `/* PORT: ... */`, doubts `/* TODO(verify): ... */`; no other comment styles. Code addresses stored in data go through `fn_origin()`/`fn_resolve()`. SDL and file I/O only in `host.c`/`main.c`. Never shadow original state in a C global. Do not reformat files owned by another module.
- **`port/src/symbols.h` is generated** — never hand-edit; use a local `#define` with the raw address where the generator emits no name.
- **Tests:** one area file per subsystem (`test_platform.c`, `test_game.c`, `test_fight.c`, `test_audio.c`, `test_video.c`), registered once via `X(test_foo)` in `TEST_CASES` (`port/tests/test.h`). Only `CHECK`/`CHECK_EQ_INT`. **Assertions must be able to fail:** seed sentinels differing from the post-condition, prove the assertion fails under a mutation, never assert an unseeded BSS-zero. `game_init()` runs once per process — env-gate any test that calls it. Consolidating tests must not change an assertion.
- **Run from the repo root.** `data/` is read-only and git-ignored; oracles skip silently without `PR_ORACLE_REQUIRED=1`. No worktree (it lacks `data/`); branch `all-gaps`, in place. 0 warnings; no new dependency.
- **Commits:** style `<area>: <what changed>`, stage named files only (never `git add -A`), commit incrementally — **but only when the user has authorised committing** (`AGENTS.md`: "Only commit when asked"). Until then, steps that say "Commit" are checkpoints where the executor stops and asks.
- **Host-owned / deferred is a valid closure** for a function only with an evidence line in `tools/port_classification.txt` (`ADDR CLASS record-§N`) and a derivation-record row naming the port's replacement.
- **Docs:** append a paragraph per cycle to `docs/PROGRESS.md`; keep `README.md`'s `— Reverse Engineering NN%` and "N% of the original's D real functions" current via `python3 tools/port_progress.py`.

## Review Focus

- A closed gap that silently changes rendering/timing/RNG: the front-end oracle stays green but under-renders (it cannot detect under-rendering). Each cycle that touches a render/timing path also re-runs `make demo-fight-oracle attract2-oracle` and diffs the frame dumps before/after.
- A function ported twice under different headers (happened in §50-B): the cycle's test asserts `grep -c '/\* 0xADDR' port/src` is exactly 1 per new address.
- A ported function that no live path reaches (unreachable arm, e.g. the `+0x42` gate at `fight_health_sync`): the derivation record states reachability, and the test drives it directly with a seeded `mem[]`.
- A `TODO(verify)` "resolved" by reading the port's own comment instead of the raw: every resolution cites a raw address or a capture frame.
- `PR_ORACLE_REQUIRED` unset making a red run look green: every verification step below sets it.

### Task 2: `TODO(verify)` sweep

**Files:**
- Modify: the files listed in ledger `§C` (`port/src/host.c`, `platform/gfx.c`, `platform/gra.c`, `platform/audio/{ail,mixer,sequencer}.{c,h}`, `game/{flow,fight,config,fighter}.c`)
- Test: the owning area file for each resolved doubt (`test_platform.c`, `test_audio.c`, `test_game.c`, `test_fight.c`)
- Create: `docs/superpowers/plans/2026-09-29-todo-verify-derivations.md`

**Interfaces:**
- Consumes: ledger `§C`.
- Produces: derivation record `§1..§N`, one section per doubt, verdict ∈ {resolved-as-is, resolved-with-fix, named-gap-with-evidence}; the marker is removed (resolved) or rewritten as a `PORT:`/named-gap comment citing the record section.

- [ ] **Step 1: Derive each doubt from the raw**

One doubt at a time: state the question, fetch the raw (`ghidra_decompile_function` / disassembly at the cited address; DOSBox-X memory dump for runtime behaviour such as the `0x2D62C` interrupt vector or the mixer's voice exhaustion), and write the verdict with the address that proves it. Doubts that need a hardware capture the repo does not have (e.g. host.c's `SDL_OpenAudioDeviceStream` failure branch, which is host behaviour, not original behaviour) are classified `PORT:` host deviations, not gaps.

- [ ] **Step 2: For each resolved-with-fix, write the failing test first**

Seed a `mem[]` sentinel that differs from the raw's post-state, assert the raw's post-state, e.g.:

```c
DSW(DS_00105EFC) = 0xDEAD;                 /* sentinel != raw post-value */
fighter_xxxx(slot);                        /* the function under fix     */
CHECK_EQ_INT(DSW(DS_00105EFC), RAW_VALUE); /* RAW_VALUE from record §N   */
```
(`RAW_VALUE` and the address are filled from the derivation record for that doubt; a doubt without a pinned value stays a named gap.) Run `PR_ORACLE_REQUIRED=1 ./build/run_tests`; expected FAIL on the new assertion only.

- [ ] **Step 3: Fix, re-run, mutate**

Apply the minimal change; `cmake --build build && PR_ORACLE_REQUIRED=1 ./build/run_tests` passes; revert the fix (or flip the constant) and confirm the new assertion fails; restore.

- [ ] **Step 4: Verify the gate**

```bash
make verify
```
Expected: exit 0, every oracle line identical to `§A`, suite total = baseline + the new assertions.

- [ ] **Step 5: Docs and checkpoint**

Append a PROGRESS.md paragraph; ledger `§C` rows marked closed with the record section. Commit (if authorised): `port: resolve TODO(verify) sweep (record §N)`.
