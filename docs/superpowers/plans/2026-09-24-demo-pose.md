# The demo fight's pose advance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the unported state-7 pose handler `0x39CC8` and its callees so the T-rex's pose advances, making the capture's fight-1 window `[843..1884]` fully explained (0 unexplained; the first unexplained moves from capture 843 to 1886).

**Architecture:** Derivation-first. Task 1 produces the authoritative record — it pins the divergence by runtime differential (a temporary, reverted port trace of the state-7 slot fields vs the capture's pixels and, where obtainable, the original's live RAM under dosbox-x) plus Ghidra, and applies the size gate; Task 2 ports each piece from it — one C function per original, address-tagged — gated by a raw-derived unit assertion with a mutation proof and the full ladder; Task 3 adds the gated `--demo-fight` oracle and wires it into `make verify`; Task 4 re-measures the window and records the outcome.

**Tech Stack:** C over the flat `mem[]` (SDL3 port), CMake, the repo's `CHECK`/`CHECK_EQ_INT` suite, Python 3 (`tools/title_compare.py`), Ghidra (project `rage`, `/PRAGE.EXE`) and dosbox-x for the raw.

**Spec:** `docs/superpowers/specs/2026-09-24-demo-pose-design.md`. Read it first — it is the contract.

## Global Constraints

- **The cycle's own gate:** the capture's fight-1 window `[843..1884]` — 1042 content-bearing frames — has **0 unexplained**, and the demo oracle's first unexplained content-bearing captured frame moves from **843** to **1886**. Reported before and after. Before: the whole window is unexplained (0 clean / 0 splice / 0 transition / 1042 unexplained); the 843/490 direct compare is **16 101 B / 5793 px**, the T-rex's body only.
- **No enforced oracle claim moves.** The gate is `make verify` exit 0 with: title `54 clean, 55 splice, 2 transition, 0 unexplained` and `54 clean, 57 splice, 0 unexplained`; attract `FIRST DIVERGENCE at capture frame 215`; front-end `[560..850]`/291/`2 unexplained (832, 833)` allowed by name (moved from `[560..842]`/283 by Task 2b's ruled fix: `0x2BC30`'s `RET 4` at `0x2BCEF` fixes `0x3A48E..0x3A4EA` to ctx[1]/ctx[5], plus the `0x35829` `0x186C4` re-latch, explaining captures 843..850); smk `120/120` + `41/41`; `oracle C-vs-Python: 9866 writes byte-exact`; `symbols.h` regenerating byte-identically.
- **If a correct fix moves an enforced claim:** the task **halts** and reports the old value, the new value, and the raw evidence that the new one is more faithful. If justified, the claim is updated **in the same commit** with the reason recorded. The default is no move. (The front-end window's tail — port 488/489 ↔ captures 840–842, currently splice-explained — is the expected candidate.)
- **Never ship a fitted constant.** Every value is derived from the raw bytes or a capture, with the address that proves it. A value that cannot be pinned is a **named gap with its evidence**.
- **On any plan-vs-raw conflict the raw wins** — record the correction and its address.
- **One C function per original function**, header comment `/* 0xADDR — spec section */`. Deliberate deviations `/* PORT: ... */`; doubts `/* TODO(verify): ... */`. No other comment styles in `port/src`.
- Code addresses stored in data go through `fn_origin()` / `fn_resolve()`. SDL and file/asset I/O live only in `port/src/host.c` and `main.c`. **Never shadow original state in a long-lived C global.** `port/src/symbols.h` is generated — never hand-edit it.
- **0 warnings**, no new dependency, `data/` read-only. Never `git add -A`. Commit style: `<area>: <what changed>`.
- **Tests:** one `int test_X(void)` per file, registered once in `TEST_CASES` (`port/tests/test.h`); only `CHECK`/`CHECK_EQ_INT`; **assertions must be able to fail** — seed sentinels that differ from the post-condition and prove the new assertion fails under a mutation of the code it tests; `game_init()` may run only once per process (env-gate any test that calls it). Assertions live in the **existing per-area files** (`test_fight.c`, `test_game.c`) — no new test file.
- **The size gate:** a group whose genuinely-new closure is **≥ ~4 KB or ≥ ~20 new functions** becomes a follow-on cycle — measured in Task 1, re-scoped **before** porting. If it triggers, the cycle stops after Task 1 and names the follow-on; the derivation is still the cycle's deliverable.
- **The branch:** `demo-pose`, in-place (no worktree — a worktree lacks the git-ignored `data/`, so the oracles would skip silently). Run from the repo root.
- **Commit incrementally** — one coherent step per commit as soon as it builds and the suite passes. Sessions die; a death must cost at most the current step.
